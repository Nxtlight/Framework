# Framework
A computational toolbox for analyzing the performance of complex adaptive systems. Numerous tools with examples and case studies.

The Reed Framework models networks in a way that captures something most other tools miss: the connections change. In the real world, people form new friendships and lose old ones; power grids add and remove transmission lines; neurons strengthen some connections and weaken others based on experience. The Reed Framework simulates this constant rewiring and then asks: given that the network is always changing, what patterns emerge? What hidden structures form? And crucially — which pieces of the network are actually in charge?
